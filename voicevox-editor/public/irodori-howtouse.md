# Irodori-TTS Vox の使い方

## この画面について

Irodori-TTS Vox は、ローカルで起動した Irodori-TTS エンジンへ接続するための画面です。VOICEVOX 本体の機能説明、音声ライブラリ、オンライン更新サービスとは連動しません。

## 起動

`bat/open_browser.bat` を実行すると、エンジンとブラウザ画面が起動します。ブラウザが自動で開かない場合は、コンソールに表示される URL を開いてください。

DirectML を使う構成では、最初の生成時にモデルと実行バックエンドを初期化します。初回だけ時間がかかることがあります。

## 音声を生成する

1. テキストを入力します。
2. Irodori-TTS 用に用意された話者・スタイルを選びます。
3. 生成または再生を実行します。
4. 生成中は進捗表示内のコンソールで、モデル読込・前処理・音声デコードの状態を確認できます。

## DirectML で止まったように見えるとき

生成中コンソールの最後の行を確認してください。`initializing model/backend` が長く続く場合は、DirectML の初期化またはモデル読込中です。

- ほかのGPUを使うアプリを閉じる
- エンジンを終了して `open_browser.bat` から起動し直す
- コンソールログにエラーがある場合は、その全文を控える

で切り分けできます。

## このビルドで扱わない機能

アクセント辞書、モーフィング、歌唱、マルチエンジン、VOICEVOX 本体のアップデート確認は、この Irodori-TTS Vox の動作対象ではありません。設定画面の案内に従ってください。
