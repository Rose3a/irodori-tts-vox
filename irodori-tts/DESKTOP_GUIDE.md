# Irodori-TTS デスクトップ起動

ルートの `Irodori-TTS.exe` をダブルクリックします。現在このPCで準備済みの `.venv` を使います。exe単体で動く完全同梱配布版ではありません。

## 普段の使い方

1. CPU / CUDA / TensorRT / Radeonを選択。選んだエンジンが裏で起動します。
2. 話者と台本を選び「生成する」（Ctrl+Enter）。生成履歴をダブルクリックすると再生できます。
3. 切り替え先のエンジンは初回のみモデル読込を待ちます。起動済みエンジンは再利用します。複数GPUエンジンの常駐はVRAMを消費するため、足りないときは「起動したエンジンを停止」を使ってください。
4. 終了時に、このUIが起動したエンジンを停止し、エンジン・モデル・話者の選択を保存します。外部で起動済みのエンジンは停止しません。

## モデル・話者をフォルダに追加

- `models/model.safetensors` はセットアップで取得した基本モデルです。
- 対応するIrodoriチェックポイントを `models` またはそのサブフォルダに置き、「モデル一覧を更新」で選べます。任意のsafetensors形式に対応するわけではありません。
- モデル変更時は「起動したエンジンを停止」→「再読込」。外部起動エンジンはそのプロセス側でモデルを設定し直します。
- TensorRTは `models/model.safetensors` と対応する `bf16-fallback/fallback_bf16.plan` の組で使います。モデルの中身を交換したらplanも再構築が必要です。
- `embeddings/*.speaker.safetensors` を置き「再読込」。基本モデルとは別の話者ファイルです。ファイルがなくても「話者なし」で生成できます。
- 生成WAVは `outputs`、起動エラーは `logs` に保存します。

## 別のPCへの準備

このexeは軽量ランチャーです。Python環境はexeに埋め込んでいません。別PCではプロジェクト一式を配置して `setup_venv.bat` を実行してください。既存venvのコピーだけでの移植は保証しません。セットアップは依存関係とモデルをダウンロードします。完全オフライン配布用インストーラー、ドライバー同梱、署名は未実装です。

TensorRTのplanはGPU・TensorRTバージョンに依存するため移行先で構築します。Radeonは既存のDirectMLワーカー環境とONNX codecの準備が別途必要です。CPU/CUDAと同じセットアップだけで全PCのRadeon動作を保証するものではありません。

公式VOICEVOX EditorのUIを使います。エンジン管理は `wrapper/desktop_runtime.py` ではなく、Editor側のElectronプロセス管理が担当します。
